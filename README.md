# Focus-Timer
A focus timer to help you get things done.

https://9mz1.github.io/Focus-Timer/

## Features
- Can be downloaded and used offline!!!
- Has a Timer mode and a Clock mode
- Other basic timer features

## Shortcuts 
- `/` Show & Hide Shortcuts
- `W` Toggle Mode
- `T` Set duration
- `SPACE` Start, Pause, Resume session
- `Q` Stop session
